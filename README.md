# Proyecto-2-curso-analisis-de-datos
Proyecto 2: Pipeline de Extracción y Modelamiento regresivo aplicable a variables predictivas multifactoriales (Python &amp; SQL)

Desarrollé un script en Python para la extracción, limpieza y preparación automatizada de datos macroeconómicos
desde la plataforma del Banco Central de Chile.

Ejecuté un Análisis Exploratorio de Datos (EDA) sobre el dataset Boston Housing, resolviendo problemas de
colinealidad y analizando variables categóricas (CHAS).

Entrené y evalué un modelo de regresión lineal con Scikit-Learn, determinando el nivel de ajuste (R²) e identificando las
variables con mayor incidencia en los precios inmobiliarios.
